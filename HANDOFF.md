## What Solaris-ui is

IT Solutions' React Native component library (Expo + react-native-web), published to npm as
`@its/solaris-ui`, with a docs site built from `apps/playground`. It is a hard fork of Glowup; the
API is being moved to MUI 9.1.1 names and the DBE-CRM generic components will be ported in. The
program, the rename table and the rules are in `docs/superpowers/specs/` (program design and
MUI-API spec). Decisions already taken there are not reopened here: MUI names with `onClick`,
`onChange` passes the value, `ButtonGroup` becomes `SegmentedButtons`, `Toolbar` keeps its name,
no react-hook-form, first npm publish is `0.1.0` at the end of sub-project 2 (G8), and the package
stays `private: true` until then.

## Decisions taken without asking (rulings)

- **A role pin is not forever.** `theme.json` pins exact roles, but an app that passes a palette
  colour replaces the default's pins for that colour's family (`familyOf`/`shadowedBy` in
  `createTheme.ts`). Without it `primary: "#B00020"` kept the blue `primaryContainer`. For
  `primary` the family also includes the neutrals derived from its hue (surfaces, outline,
  inverse roles), so a grey brand keeps grey surfaces. Cost: an app overriding only `primary`
  loses the designers' blue-grey surfaces.
- **`tertiary` is explicit** (the green), so it no longer follows primary's hue.
- **Selected filled `Chip` = `secondaryContainer`** (neutral), and `Banner type="warning"` uses
  the warning roles: with a green tertiary the old roles would have been green. G2 redefines the
  Chip variants anyway.
- **Icon colour precedence:** a `color` in `style` wins over the `color` prop (as on a
  vector-icons glyph); components pass a default in `color` and a state in `style`.
- **Eva generator** draws `path`, `circle` and `rect` (rotated about its centre) and fails on
  anything else. `polyline` icons (e.g. `flag`) are left unmapped.
- **Eva licence:** the package ships no `LICENSE` file, so `EVA_LICENSE` is the standard MIT text
  credited to `akveo` (from `package.json`), **without a year**.
- **Logo:** one component, not one per file.
- The theming test cannot assert that `#1D5B9D` is absent in dark (A's dark `inversePrimary` is
  `#1D5B9D`); it checks a light-only colour instead.

## Gotchas learned

- After touching props or previews run `npm run docgen -w @its/solaris-playground` and
  `npm run variants -w @its/solaris-playground`; CI fails on a diff. `Icon` has a hand-written
  gallery in `catalogue/variants/manual/Icon.tsx` that wins over `.design-sync/previews/Icon.tsx`.
- Run `npx eslint --fix packages/ui apps/playground .design-sync/previews` after bulk edits;
  quotes and apostrophes in JSX text must be wrapped in `{"..."}`.
- Adding a glyph to a component: add it to `iconMap.json`, then `npm run icons:eva -w
  @its/solaris-ui`; the catalogue test fails on an unmapped one.
- react-native-svg turns colours into numbers in the test tree: compare two renders, do not look
  for a hex string. AsyncStorage needs the official jest mock (see `theming.test.tsx`).
- On Windows Git Bash, inline `node -e`/heredoc scripts mangle backslashes and quotes: put the
  script in a file and run it.
- `npm run web` may find port 8081 taken by another Expo server; use `-- --port 8085`. Routes are
  case-sensitive (`/components/Button`).
- Gabriele's sessions do not commit; Alice's does when she asks. Pushing to `master` starts the
  release workflow.
